# Lead sheet columns

One row per business. Keep the order stable so sheets from different cities can be merged.

| Column | Content |
|---|---|
| Business | Name as listed |
| Trade | e.g. painter |
| City | City or district |
| Address | Street, postal code, city |
| Phone | Public business number |
| Website | URL as listed |
| Final URL | URL after redirects |
| Map link | Link to the map entry |
| Reviews | Count and average, with the source and date |
| Pre-filter | Passed, or the rule that removed it |
| Score | Scorer result, 0 to 100 (empty for no-website leads) |
| Priority | HIGH, MEDIUM, LOW or EXCLUDE. Businesses without a website: LOW, with "no website" in Notes |
| AI assessment | Four short parts: visible, works, verified defects, uncertainties; end with scope and confidence |
| Evidence | Report path, screenshot folder, date checked |
| Notes | Anything a human should know before contact |

Keep a second small sheet for progress: region, date, number of leads, file name.
